# capability-core Hermes state

This folder is the project-local Hermes execution memory for `capability-core`.

Use it instead of storing capability-core workstream state under the old Directive Kernel `.hermes/` folder.

## Resume order

Read these first:

1. `.hermes/active/CURRENT.md`
2. `.hermes/active/NEXT.md`
3. `.hermes/active/DECISIONS.md`
4. `.hermes/active/STATE.json`

Then read `HANDOFF.md`, `TASKS.md`, `BLOCKERS.md`, or evaluations only when pointed to by active state.

## Boundary

`capability-core` is the greenfield minimal successor for verified capability truth under Hermes skills. The old DK repo remains donor/reference material only unless explicitly selected.
